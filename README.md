# MailNgWordFilter for baserCMS 4

BcMail（メールフォーム）のテキストエリア（複数行入力欄）に入力された内容を検証し、特定のNGワード（禁止文字列）が含まれていた場合にバリデーションエラーを発動させて送信をブロックする、baserCMS 4系専用の迷惑メール・スパム排除プラグインです。

## 特徴

- **テキストエリアのみを対象に自動特定**: お名前やメールアドレス、件名などの1行テキスト項目を巻き込まず、お問い合わせ内容などの「複数行テキストエリア」だけを自動で狙い撃ちして検査します。
- **特定のフォームのみに限定適用**: 管理画面のチェックボックスから、フィルターを有効化したいメールフォームだけを個別に指定できます。採用エントリーや会員限定フォームなど、誤検知を防ぎたいフォームを安全に対象外にできます。

## 動作環境

- baserCMS 4.2.0 以上（推奨）
- PHP 7.x / 8.x

## インストール方法

1. GitHubからリポジトリをダウンロードするか、クローンします。
2. 解凍したフォルダ名を `MailNgWordFilter` に変更します。
3. baserCMSの設置ディレクトリの `/app/Plugin/` 内に配置します。
4. baserCMSの管理画面にログインし、「プラグイン管理」から **メール禁止ワードフィルター** を有効化します。

## 設定・使用方法

1. プラグイン有効化後、管理画面のプラグイン一覧にある「メール禁止ワードフィルター」の **設定ボタン（ギアアイコン）** をクリックします。
2. **NGワード（禁止文字列）**: ブロックしたい文言を半角カンマ（`,`）で区切って入力します。（例: `SEO集客, 投資代行, 副業紹介`）
3. **対象メールフォーム**: サイト内に作成されているメールフォームが一覧で表示されます。NGワードチェックを適用したいフォームにチェックを入れます。
4. 「保存」ボタンをクリックすると、設定ファイル（`Config/setting.php`）が自動的に書き換わり、即座にフィルターが有効になります。

## ファイル構成

```text
MailNgWordFilter/
├── config.php          # プラグイン定義ファイル
├── README.md           # 本ドキュメント
├── VERSION.txt
├── Config/
│   └── setting.php     # 設定保持ファイル（自動更新）
├── Controller/
│   └── MailNgWordFilterConfigsController.php  # 設定画面コントローラー
├── Event/
│   └── MailNgWordFilterModelEventListener.php # バリデーションフックイベント
├── Model/
│   └── MailNgWordFilterConfig.php             # テーブルなしダミーモデル
└── View/
    └── MailNgWordFilterConfigs/
        └── admin/
            └── form.php # 設定画面ビューテンプレート
```
